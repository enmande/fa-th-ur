Palette notes: Dim amber, gold, soft black. Code blocks sit on a dark "screen" in both modes. Inline code in light mode is umber ink on paper.

Palette

Contrast

Each pair must meet its WCAG 2.2 minimum ratio. The build stops when a pair fails. Targets: 7:1 (AAA) for body text, 4.5:1 (AA) for secondary text and code tokens, 3:1 for UI borders.

Code screen

Each sample shows the theme colors and three simulated color-vision differences. The simulation uses the Machado (2009) matrices at full severity.

Color distance by vision type

OKLab ΔE × 100 between two code roles, after simulation. Guide: under 5 is hard to tell apart in small text. 5 to 10 is noticeable. 10 or more is clear.
