A warm, minimal, accessible theme framework. Soft blacks, dim ambers, aged paper, and a green phosphor screen for code.

Palette notes: Dim amber, gold, soft black. Code blocks sit on a dark "screen" in both modes. Inline code in light mode is umber ink on paper.

Contrast

Each pair must meet its WCAG 2.2 minimum ratio. The build stops when a pair fails. Targets: 7:1 (AAA) for body text, 4.5:1 (AA) for secondary text and code tokens, 3:1 for UI borders.
