# Welcome to fa-th-ur

This vault is a style sheet for the **fa-th-ur** theme. Each note shows one group of features. Open each note in Reading view and in Live Preview.

## Notes

1. [[Typography]]: headings, text styles, links, quotes, footnotes
2. [[Lists and tables]]: lists, tasks, tables
3. [[Callouts]]: every callout type
4. [[Code]]: inline code and code blocks in several languages
5. [[Embeds and media]]: embeds, math, diagrams, images
6. [[Board.canvas|Board]]: a canvas with colored cards
7. [[HTML elements]]: each common HTML element, written as raw HTML in a note

The [[Logs/Interface room|Logs]] folder holds short notes for the file explorer and the graph view.

## Checklist for a trial

- [ ] Switch between the dark and light themes (Settings > Appearance).
- [ ] Switch the window frame style: Hidden, Obsidian frame, Native frame.
- [ ] Open the graph view.
- [ ] Open the command palette and the settings window.
- [ ] Search for "lorem".
