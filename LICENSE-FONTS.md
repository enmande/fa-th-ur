# Font licenses

`dist/obsidian/fa-th-ur/theme.css` embeds these fonts. Each font uses the SIL Open Font License 1.1. The full license text is in `src/fonts/<font>/OFL.txt`. The build also copies each license into the theme folder as `OFL-<font>.txt`.

| Font | Copyright | Embedded form |
|---|---|---|
| JetBrains Mono | Copyright 2020 The JetBrains Mono Project Authors | Character subset, WOFF2 |
| IBM Plex Sans | Copyright 2017 IBM Corp. with Reserved Font Name "Plex" | Unmodified original TTF files |

IBM Plex Sans has the Reserved Font Name "Plex". The OFL does not permit that name on a Modified Version, so the build embeds the original IBM Plex Sans files without subsetting or instancing.
